# Chloe Chan — Personal Website

Personal site for Chloe Chan, MSc Marketing candidate at HKU.

## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g. `chloe-chan.github.io`).
2. Drag and drop these files into the repo root:
   - `index.html`
   - the `assets/` folder (contains `chloe-photo.png`)
3. Go to **Settings → Pages**, set source to **Deploy from a branch → main / root**, and save.
4. Site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute.

## Files

└── assets/
